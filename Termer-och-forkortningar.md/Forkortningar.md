# Termer och förkortningar

| Term            | Förklaring                                                                       |
| --------------- | -------------------------------------------------------------------------------- |
| E2E             | End-to-end, test av ett helt flöde från början till slut                         |
| API             | Kommunikation mellan olika system                                                |
| Regressionstest | Test för att kontrollera att tidigare fungerande funktioner fortfarande fungerar |
| Testmiljö       | Miljö där systemet testas utan att påverka produktionen                          |
| Testobjekt      | Det är en del av systemet som ska testas                                         |
| Extern tjänst   | Ett system som NordicShop inte själva äger, exempelvis betalningstjänsten        |
