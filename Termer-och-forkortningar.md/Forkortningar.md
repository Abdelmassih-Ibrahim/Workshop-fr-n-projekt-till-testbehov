
# Termer och förkortningar

| Term             | Förklaring                                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------------------------- |
| E2E              | End-to-End. Testning av ett komplett flöde från början till slut.                                                     |
| API              | Application Programming Interface. Ett sätt för system att kommunicera med varandra.                                  |
| Regressionstest  | Testning som görs för att kontrollera att tidigare fungerande funktionalitet fortfarande fungerar efter förändringar. |
| Testmiljö        | Miljö där systemet och dess funktioner testas innan produktion.                                                       |
| Testobjekt       | Det som ska testas, exempelvis en applikation, funktion, tjänst eller integration.                                    |
| Integrationstest | Testning av kommunikationen mellan olika system eller komponenter.                                                    |
| Systemtest       | Testning av hela systemets funktionalitet mot specificerade krav.                                                     |
| Acceptanstest    | Testning för att kontrollera om systemet uppfyller verksamhetens behov och krav.                                      |
| Mock             | Sami vet.                                |
| Testdata         | Data som används för att genomföra tester.                                                                            |
| Felrapport       | Dokumentation av ett upptäckt fel, exempelvis vad som hände, hur felet kan återskapas och vilken påverkan det har.    |
| Stakeholder      | Person, grupp eller organisation som påverkas av projektet eller har intresse i projektet.                            |
| MVP              | Minimum Viable Product. Den första versionen av produkten med den funktionalitet som krävs för att kunna lanseras.    |
| Backend          | Den del av systemet som hanterar logik, data och kommunikation bakom användargränssnittet.                            |
| Frontend         | Den del av systemet som användaren interagerar med, exempelvis webbplats eller mobilapp.                              |
| Order Service    | Systemdel som hanterar orderrelaterad funktionalitet.                                                                 |
| Teststatus       | Sammanställning av hur testningen fortskrider och vilka resultat som uppnåtts.                                        |
| Testledare       | Rollen som ansvarar för att planera, styra och följa upp testarbetet.                                                 |
