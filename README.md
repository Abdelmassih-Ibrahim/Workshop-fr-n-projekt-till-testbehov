# Workshop-från-projekt-till-testbehov

## Om projektet
- Detta är ett pilotprojekt utformat för att praktisera testledning och kvalitetssäkring i ett avgränsat system. 
- Syftet är att etablera strukturerade processer för kravanalys och planering.
- Vi övar på riskbedömningar och analyserar externa & interna integrationer.
- Vi identifierar relevanta Stakeholders och vilken information som saknas från Testledares perspektiv.
